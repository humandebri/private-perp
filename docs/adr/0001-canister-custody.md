# ADR-0001：Canisterによる資金保管

- 日付：2026-09-18
- 設計状態：accepted
- 実証状態：未実装・未実証。UIデモは資金・暗号化・ガバナンスの証明ではない

## 背景

普段使いウォレットとHL口座のリンクを減らしたい。Agent-onlyでは入金経路が公開され、今回の目標を単独では満たせない。

## 比較した案

Agent-only、機密資金層＋ユーザー別HL口座、単一HL口座での内部ポジション管理を比較した。

## 決定

機密資金層が顧客資金を管理する方式を採用する。運営予算と顧客資金を分離し、資金の複式台帳・本人認可・出金・復旧を実装対象に含める。共通保管だけで相関が隠れるとは扱わない。

## 欠点・残存リスク

Canister停止や不具合で資金回収が止まり得る。鍵の分散は非カストディや安全性を意味しない。法務・独立監査・相関評価の負担が増える。

## 再検討条件

往復送金の安全性、相関試験、法的適合性のいずれかが未達の場合。自動でAgent-onlyや単一口座へ切り替えず、設計判断を更新する。
