## Established results

- `Implementation.md` 9.1 item 1: identical encoding/digests for the same SDK inputs. The SDK does not expose intermediate values, so evidence is **exact action-hash equality (`createL1ActionHash`)** and **exact deterministic signature equality (RFC6979)** across all 11 fixtures.
- Item 2: action field order, integer representation, and decimal normalization. Minimal `hl-types::msgpack` representations match SDK `@std/msgpack` encoding, including uint64 for `oid = 4294967297` in `cancel_large_oid.json`.
- Item 3: agent signature wrapping and EIP-712 domains/types. Fixtures match both phantom agent (`Exchange` / `1` / `1337` / `0x0`, `Agent(source, connectionId)`) and user-signed (`HyperliquidSignTransaction`, `ApproveAgent` / `UsdSend`) paths.
- Item 4: `v` recovery. Assuming tECDSA replies lack `v`, implemented `recover_v` to choose between 27/28 by public-key equality; unit tests also reject incorrect public keys.
- Item 5: fixed regression tests run with `cargo test`.
