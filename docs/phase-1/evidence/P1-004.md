- Date: 2026-09-19 (last updated 2026-09-21)
- Scope: `crates/funds-vault/src/fund.rs`, `crates/db/src/repo/{ledger,funds,events,actions}.rs`
- Check: `bash scripts/pocket-ic-test.sh --test vault_funds` (**six passes**)

## Checks performed

| Test | Behavior |
|---|---|
| `allocation_without_funds_is_rejected` | Reject zero-balance allocations with `InsufficientFunds` |
| `allocation_is_idempotent_and_bounded_by_the_balance` | Create reservations; duplicate requests do not reserve twice; changed bodies return `IdempotencyConflict`; reservations reduce withdrawable funds; reject over-balance requests |
| `withdrawal_requires_a_valid_intent_signature` | Reject wrong-key, wrong-destination, and expired intents; accept only valid signatures |
| `a_withdrawal_reservation_over_half_the_balance_keeps_reads_working` | Reads do not return `Invariant` when reservations exceed remaining unallocated funds; consolidate holds in one place |
| `a_withdrawal_intent_nonce_cannot_be_reused` | Signed withdrawal nonces are single-use; reject the same signature under another admission ID |
| `a_session_from_another_caller_is_rejected` | Another caller using the session receives `Unauthenticated` |

## Design decisions

- Withdrawal intent: `PrivatePerpWithdrawal(address eoa,uint64 amount,string asset,string destination,string network,uint64 nonce,uint64 expiresAt,bytes canister)`. Do not sign internal user/account IDs unavailable to clients.
- Construct the send action when building the wire payload during signing, so `FundRequestAccepted.fund_action_id` is `Option`.
- Test deposit crediting (`test_credit_deposit`) compiles only with `test-venue` and is absent from production builds.

## Deposit receiver checks performed

`bash scripts/pocket-ic-test.sh --test vault_deposits` (**two passes**): prepare a destination with `provision_reserve_account`; **credit deposits to the owner's destination as unallocated balance**; **do not duplicate a tx_hash**; **record unknown destinations without assigning them arbitrarily**. Reject noncontrollers and empty hashes. Replicated `/info` transport is checked below. Additional `an_unmatched_deposit_can_be_claimed_by_the_controller` checks unknown deposits in suspense and owner assignment through controller `claim_unmatched_deposit`.

## Full deposit-path checks including transport

`bash scripts/pocket-ic-test.sh --test vault_reconcile` (one pass): retrieve `/info` `userNonFundingLedgerUpdates` through **replicated outcalls and a deterministic transform**, retaining only `hash`, `time`, and `delta.usdc`, then ingest. **Credit the owner** with 100.5 USDC (100,500,000 micro units), **do not duplicate hashes**, and reject noncontrollers.

Periodic heartbeat calls `reconcile_all`, traversing with a `(created_at, master_address)` cursor without stopping on one failure. Unknown deposits enter suspense and controllers assign them through `claim_unmatched_deposit` (commit `97ae049`).

## Allocation receipt and recovery round-trip checks

`bash scripts/pocket-ic-test.sh --test vault_recovery` (**three passes**): receipts to trading accounts use `allocation_confirm` (in-transit→trading); reserve receipts use `deposit_confirmed`. **Trading balance increases and in-transit becomes zero**. Then `request_recovery` and a mock-accepted send **empty the trading account back into reserve**, settling the request. Retrieve the trading address with `get_trading_address(session)`. `a_recovery_over_the_trading_equity_is_rejected` rejects recovery above equity; `a_direct_deposit_to_the_trading_account_is_credited` credits direct trading deposits outside in-transit allocations.

## Measured replicated-info implementation notes

- Use `HttpRequest::with_transform(TransformContext)` and construct the context with `ic_cdk_management_canister::transform_context_from_query(method_name, context)`.
- **Transform return type is `ic_cdk_management_canister::HttpRequestResult`**; `HttpResponse` does not exist in the 0.10 series. Use fully qualified signatures: `fn transform_info(args: ic_cdk_management_canister::TransformArgs) -> ic_cdk_management_canister::HttpRequestResult`. Otherwise `export_candid!` cannot resolve type names in lib.rs.
- Retrieve deposits from `/info` `userNonFundingLedgerUpdates` (`{time, hash, delta:{usdc}}`). Retain only those fields for deterministic transformation and convert decimal amounts to integer micro units.
